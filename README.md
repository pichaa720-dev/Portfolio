# 🌟 Personal Portfolio Website

เว็บไซต์แฟ้มสะสมผลงาน (Portfolio) ส่วนตัว พัฒนาแบบ **Multi-Page Website** ด้วย HTML5, CSS3 และ JavaScript ตอบสนองทุกขนาดหน้าจอ (Responsive Design) รองรับทั้ง Dark Mode และ Light Mode

---

## 📑 หน้าเว็บทั้งหมด (Pages)

1. **Home (`index.html`)**: หน้าแรก แนะนำตัว ประวัติย่อ สถิติผลงาน ทักษะความเชี่ยวชาญ และลิงก์สำรวจ
2. **Education (`education.html`)**: ข้อมูลการศึกษาทุกระดับชั้น (ประถม, ม.ต้น, ม.ปลาย, ปริญญาตรีเกียรตินิยม) พร้อมใบรับรองวิชาชีพ
3. **Portfolio (`portfolio.html`)**: แกลเลอรีผลงานซอฟต์แวร์และโปรเจกต์เด่น พร้อมระบบคัดกรองหมวดหมู่ และปุ่มดูรายละเอียด (Modal)
4. **Activity (`activity.html`)**: ประวัติกิจกรรม การแข่งขัน Hackathon ค่ายอบรม สัมมนา และงานจิตอาสา
5. **Contact (`contact.html`)**: ข้อมูลติดต่อครบถ้วน โซเชียลมีเดีย และแบบฟอร์มส่งข้อความ

---

## 🎨 ฟีเจอร์เด่น (Key Features)

- **Multi-Page Structure**: แยกแต่ละหน้าเว็บอย่างชัดเจนตามมาตรฐาน พร้อม Header นำทางระบุหน้าปัจจุบัน (Active State)
- **Unified Footer**: ส่วนท้ายเว็บไซต์เหมือนกันทุกหน้าตามข้อกำหนด พร้อมลิงก์ด่วนและปุ่ม Back to Top
- **Dark / Light Theme Toggle**: สลับโหมดการแสดงผลได้ตามต้องการ และจดจำสถานะผ่าน `localStorage`
- **Mobile Responsive**: รองรับการแสดงผลบนหน้าจอสมาร์ทโฟน แท็บเล็ต และคอมพิวเตอร์อย่างสมบูรณ์แบบ
- **Interactive Components**: ฟิลเตอร์หมวดหมู่ผลงาน, หน้าต่างป๊อปอัปพรีวิว, การแจ้งเตือน Toast Alert เมื่อส่งแบบฟอร์ม

## 🚀 การเปิดใช้งาน GitHub Pages

เมื่อโปรเจกต์นี้อยู่บน GitHub คุณสามารถเปิดให้คนทั่วไปเข้าชมผ่านเว็บเบราว์เซอร์ได้ฟรีด้วยขั้นตอนง่ายๆ:
1. เข้าไปที่ Repository: [pichaa720-dev/Portfolio](https://github.com/pichaa720-dev/Portfolio)
2. ไปที่แท็บ **Settings** > เมนูด้านซ้ายเลือก **Pages**
3. ในส่วน **Build and deployment** > **Branch**:
   - เลือก Branch: `main`
   - เลือก Folder: `/ (root)`
   - คลิก **Save**
4. รอระบบประมวลผลประมาณ 1-2 นาที เว็บไซต์จะออนไลน์ที่:
   👉 **`https://pichaa720-dev.github.io/Portfolio/`**
